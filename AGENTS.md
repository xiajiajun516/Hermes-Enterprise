# AGENTS.md — Hermes & Multi-Agent Project Instructions

This project defines the **Software Engineering AI Team Skill** based on Subagent-Driven Development and TDD.

## Core Directives
1. **Artifact-Driven**: All major planning, design, and review decisions must be written to `artifacts/` (`spec.md`, `architecture.md`, `compliance-report.md`).
2. **Compliance First**: All specs must pass static audit against `references/rules/` before code implementation begins.
3. **Strict TDD**: Engineers must follow RED-GREEN-REFACTOR cycles, writing tests alongside or before implementation.
4. **Approval Required**: High-risk actions (deletions, DB migrations, env modifications) must trigger explicit approval.
